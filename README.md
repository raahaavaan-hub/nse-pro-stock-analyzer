# NSE Pro Streamlit V1

Files:
- app.py
- requirements.txt

Deploy:
1. Create a GitHub repo.
2. Upload both files.
3. Open Streamlit Community Cloud.
4. Create app -> choose app.py.
5. Use Python 3.12.
6. Deploy.

Features:
- Internet-based Pro Analyzer
- Swing screener presets
- All NSE performance 1D to 5Y
- CSV export to replace manual closing-price entry
- Institutional/FII-DII section that does not fake ownership data

Data:
- NSE official equity master list for symbols
- yfinance/Yahoo for free prototyping of OHLCV
